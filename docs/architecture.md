# Архитектура

```text
Npcap
  └─ TCP payloads
      └─ GameStreamReassembler
          └─ DpsPacketParser
              ├─ damage / heal / identity / target events
              └─ DataRepository
                  └─ DpsCalculator
                      └─ MeterRuntime snapshot
                          └─ MeterViewModel
                              └─ WPF overlay
```

## Границы

`AionFlex.Core` содержит DTO, enum, боевые модели и интерфейсы. Он не знает о UI или сетевом драйвере. Пока проект компилирует весь перенесённый Core, в том числе модели подсистем, которые сам метр не использует. Отсечение этих типов требует отдельной проверки зависимостей и не выполняется механическим удалением файлов.

`AionFlex.Infrastructure` скомпилирован по явному whitelist файлов. В сборку попадают только:

- `NpcapCaptureService` и watchdog;
- `GameStreamReassembler`;
- диагностика протокола;
- `PacketParsing/Dps` и декодер коллекции питомцев.

Код Auth, Licensing, Telemetry, Updating, Settings, Sessions, Armory и WindowManagement не компилируется и не попадает в итоговые DLL.

`AionFlex.Application` содержит хранилище данных, DPS-калькулятор, разрешение владельцев призывов и репозитории игровых справочников.

`Aion2Meter` владеет жизненным циклом приложения и захвата, календарём, настройками, связывает события и преобразует боевой snapshot в UI-модель. В одном сеансе Windows запускается не более одного экземпляра; при закрытии во время инициализации созданный позже runtime освобождается.

`tests/Aion2Meter.Smoke` без внешних тестовых пакетов проверяет строки UI, высоту окна до десяти участников, порядок уведомлений, TCP-последовательности, блокировку второго экземпляра, настройки с резервной копией, диагностику и календарь. Проверки запускаются локально и в CI до упаковки релиза.

## Режимы запуска

Обычный запуск загружает JSON-справочники, открывает Npcap devices и начинает захват. Очередь payload ограничена; потери фиксируются в диагностике. Аргумент `--demo` не запускает Npcap и генерирует детерминированный live snapshot для UI-разработки.

## Данные

В publish-каталог копируется каталог `data`, включая справочники, карты и иконки:

- skills, NPC skills, theostones;
- skill effect types и summon skills;
- mobs и NPC summons;
- class icons, иконки навыков, питомцев и тайлы карт.

Пути к неизменяемым данным строятся от `AppContext.BaseDirectory`, поэтому exe можно запускать из любой рабочей папки. Настройки и новые диагностические журналы пишутся в `%LOCALAPPDATA%\Aion2Meter`, а не в каталог установки. При переходе со старой сборки имя активного персонажа можно восстановить из прежнего журнала рядом с EXE; файлы не удаляются автоматически.
