# Aion 2 DPS v0.2.10

Установщик для Windows: `Aion2Meter-Setup-v0.2.10.exe`. Переносная сборка: `Aion2Meter-win-x64.zip`. Обе сборки включают .NET; Npcap при необходимости устанавливается отдельно через официальный мастер.

Что изменилось:

- Добавлен переключаемый лёгкий вид группы: полупрозрачный фон, игровые иконки классов, имя, место и показатели урона без отдельных плашек и полос. Обычный вид остаётся по умолчанию.
- В разборе игрока появились изображения навыков, сведения о выбранных пассивных умениях и вариантах развития навыков, когда эти данные доступны в сетевом потоке.
- Дебафы на текущей цели от других игроков можно показывать отдельной настройкой.
- Исправлены определение локального персонажа после перезахода, выбор мирового босса для подсчёта DPS и разбор некоторых повторяющихся сетевых пакетов.
- Добавлена проверка обновлений при запуске с возможностью отключить её в настройках. Установщик скачивается с GitHub Releases, проверяется по размеру и SHA-256 и запускается только после подтверждения пользователя.
- Диагностический журнал теперь продолжается в новых частях после достижения лимита, а не прекращает запись.

Настройки пользователя в `%LOCALAPPDATA%\Aion2Meter` при обновлении сохраняются.
