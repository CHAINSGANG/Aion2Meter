# Разбор интерфейса AionFlex

Источник проверки: декомпилированные `OverlayWindow.xaml`, `OverlayWindow.xaml.cs`,
`DashboardWindow.xaml` и связанные ViewModel из локальной сборки пользователя
из предоставленной локальной папки AionFlex.

## Оверлей

| Элемент AionFlex | Фактическое действие | Состояние в Aion II Meter |
|---|---|---|
| PvE / PvP | Переключает два разных overlay mode | PvE-ядро подключено; PvP ещё не подключён |
| Party | Открывает отдельную проверку состава комнаты подземелья | Работает: состав, классы, уровень, GS, боевая мощь и статус в подземелье |
| `✚` | Переключает отображение лечения | Работает как отдельный режим статистики: HPS, лечение, доля и навыки |
| Damage taken | Переключает входящий урон | Работает как отдельный режим: противники, входящий урон/с, общий урон и атаки |
| Density | Normal / Compact / Micro | Сейчас есть подробный и компактный режимы |
| Training | Запись, остановка и сравнение попыток на манекене | Не подключено |
| Dashboard | Открывает общий центр функций | Кнопка инструментов есть, содержимое будет переноситься по этой карте |
| Reset | Сбрасывает текущий бой | Работает |
| Mechanics | Открывает панель механик босса | Не подключено |
| Event timers | Календарь рифтов, осад, боссов Бездны, Shugo Festival и Invasion | Работает локально; часы сервера читаются из игрового пакета |
| Copy chat | Копирует сводку боя для игрового чата | Не подключено |
| Screenshot | Копирует изображение группы в буфер обмена | Не подключено |
| Lock | Фиксирует окно и включает click-through | Не подключено |
| Close | Завершает приложение | Работает |
| Строка игрока | Открывает breakdown игрока | Работает: навыки, удары, криты, спина, двойные/мощные, DPS, средний/максимальный урон и доля |
| Boss / All | Фильтрует урон только в босса либо во все цели | Работает; находится в нижней строке компактного режима |
| Opacity | Плавная пользовательская прозрачность | Реализованы три требуемых уровня |

## Данные, которые уже отдаёт восстановленный парсер

- урон, лечение, критические и качественные удары;
- входящий урон и защитные исходы;
- имя и entity id локального персонажа;
- имена и классы участников;
- цель игрока и HP сущностей;
- призывы и их владельцы;
- состав Party Dungeon room;
- состояние подземелья и результат прохождения;
- лут-энергия, игровые счётчики, ростер персонажей;
- полевая активность, задержка, сервер и часть loadout-данных.

Текущая оболочка намеренно подключает сначала только DPS-путь. Остальные функции
нельзя обозначать как готовые карточки, пока их события, состояние и окна не связаны
сквозным рабочим сценарием.

## Порядок переноса

1. Стабильный DPS-оверлей: локальный персонаж, группа, цель, HP, Boss/All, плавность — подключён.
2. Breakdown по клику строки, копирование, снимок, лечение и входящий урон — подключены.
3. Party check, страница питомцев и календарные уведомления — подключены; тренировка, история боёв и PvP следующие.
4. Механики, проки, живые таймеры полевых боссов, ростер и остальные страницы Dashboard.
