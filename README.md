# Aion II Meter

Компактный DPS-метр для Aion 2 с отдельным WPF-overlay. Он пассивно читает локальный игровой трафик через Npcap, не внедряется в процесс игры и не модифицирует память клиента.

## Что уже работает

- пассивный захват TCP-трафика через Npcap;
- реассемблирование потока и декодирование damage/heal-событий;
- автоопределение игроков, классов, призывов и цели;
- режимы «Босс» и «Все цели»;
- отдельные рабочие режимы нанесённого урона, лечения (HPS) и полученного урона;
- страница питомцев с именами, семействами, уровнями и бонусами из игровых справочников;
- поиск мест обитания питомцев на настоящих картах клиента, ближайшая точка и живой маршрут от персонажа;
- отдельная проверка состава Party Dungeon room: классы, уровни, GS и боевая мощь;
- плавная анимация перестановки строк при изменении рейтинга DPS;
- локальный календарь рифтов, осад, боссов Бездны, фестиваля шуго и пространственных вторжений;
- ранние предупреждения с живым отсчётом, синхронизированные по часам сервера из игрового пакета;
- сортировка участников по текущему DPS;
- одновременный показ DPS/с, общего урона и доли группового урона;
- разбор навыков игрока по клику на его строку;
- текущая цель, её HP и время боя всегда видны в верхней сводке;
- старт в компактном режиме с локальным персонажем и явный переключатель «Я / Группа»;
- три уровня прозрачности;
- шрифт, оконные значки, DPS-атлас и рамка HP извлечены из ресурсов Aion 2;
- отдельная кнопка открывает центр инструментов, не перегружая DPS-оверлей;
- пауза UI, сброс боя, always-on-top;
- demo-режим для работы над дизайном без запущенной игры.

Центр управления содержит только рабочие действия: фильтр целей, «Я / Группа», размер окна, прозрачность, паузу, сброс, копирование текстовой сводки и снимка оверлея. Остальные модули перечислены только как результат аудита и не выдают себя за готовые функции.

## Установка готовой версии

1. Скачайте `Aion2Meter-Setup-v*.exe` со страницы Releases.
2. Запустите установщик и выберите нужные ярлыки.
3. Если Npcap ещё не установлен, мастер сам скачает подписанный установщик с `npcap.com`, проверит SHA-256 и запустит его — браузер открывать не придётся.

Релиз автономный и не требует отдельного .NET Desktop Runtime. Npcap не вложен в публичный архив: он загружается напрямую с официального сервера и ставится своим графическим мастером, как в AionFlex. Метр сам запускает службу Npcap перед захватом, а при обычном закрытии освобождает захват и останавливает её; драйвер остаётся установленным для следующего запуска.

## Сборка из исходников

Требуются Windows и .NET 10 SDK. Для реального захвата трафика также нужен Npcap.

```powershell
dotnet build .\Aion2Meter.slnx -c Release
dotnet run --project .\src\Aion2Meter\Aion2Meter.csproj
```

Demo-режим:

```powershell
dotnet run --project .\src\Aion2Meter\Aion2Meter.csproj -- --demo
```

Для проверки компактного режима и центра инструментов:

```powershell
dotnet run --project .\src\Aion2Meter\Aion2Meter.csproj -- --demo --compact --tools
```

Готовая автономная сборка для выдачи:

```powershell
.\scripts\publish.ps1
```

Для локальной сборки полноценного установщика сначала подготовьте проверенный portable-компилятор Inno Setup:

```powershell
$iscc = .\scripts\prepare-inno.ps1
.\scripts\publish.ps1 -Version 0.2.2 -InnoCompiler $iscc
```

Результат появится в `artifacts\release`: готовый `Setup.exe`, его SHA-256 и переносной ZIP как запасной вариант.

## Структура

- `src/Aion2Meter` — новый UI и тонкий runtime-координатор;
- `src/AionFlex.Infrastructure` — только Npcap, TCP reassembly и DPS packet parser;
- `src/AionFlex.Application` — хранилище боевых событий, справочники и DPS calculator;
- `src/AionFlex.Core` — совместимые модели и интерфейсы;
- `docs/architecture.md` — поток данных и границы модулей.
