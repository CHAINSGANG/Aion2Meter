AION II METER
==============

1. Полностью распакуйте ZIP-архив.
2. Запустите Install.cmd.
3. Подтвердите запрос Windows при первом запуске метра.

Сборка автономная: отдельный .NET Desktop Runtime не требуется.

Npcap не входит в архив из-за условий его лицензии. Если драйвер ещё не
установлен, установщик откроет официальную страницу загрузки Npcap.

При обычном закрытии Aion II Meter захват пакетов освобождается, после чего
служба Npcap останавливается. Сам драйвер остаётся установленным и будет
доступен при следующем запуске метра.
